## Estrutura do projeto

```
curriculo-github/
│
├── index.html     # Página principal: objetivo, formação, habilidades e experiência

└── README.md      # Este arquivo
```

## Como visualizar

1. Clone o repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/curriculo-github.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd curriculo-github
   ```

3. Abra o arquivo `index.html` no navegador (dois cliques no arquivo).

## Tecnologias

3. A branch foi integrada à `main` por meio de um Pull Request.
